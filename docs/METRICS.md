# 指标手册 · 我们关注什么、阈值多少、为什么

> 本手册是「北民大格雷厄姆的 ValueDesk」的"判断依据全集"。
> 每条指标都有：**定义 → 健康阈值 → 为什么关注 → 出问题时的年报核查方向**。
> 财务术语默认你有基础（三张表 / ROE / 估值），不解释概念，只讲判断。

---

## 一、指标体系总览（五组）

| 组 | 回答什么问题 | 核心指标 |
|---|---|---|
| ① 盈利质量 | 这公司**持续**赚钱吗？赚的是什么质量的钱？ | ROE（杜邦拆解）、毛利率、扣非占比、ROE 趋势 |
| ② 资产安全 | 资产负债表里有没有埋雷？ | 负债率、存贷双高、应收、存货、商誉 |
| ③ 现金流 | 利润是真金白银还是纸面数字？ | 5年累计含金量、连续负年数、自由现金流 |
| ④ 成长 | 是成长还是老龄化？增长的质量如何？ | 营收/净利 CAGR、增速稳定性 |
| ⑤ 股东回报与估值 | 现在的价格值不值得？回报是否实在？ | 股息率、分红连续性、PE/PB |

**阅读顺序建议：先②③（安全与真实性），再①④（质量与成长），最后⑤（价格）。**
先确保不踩雷，再谈买得好不好。

## 二、逐指标详解

### ① 盈利质量

**ROE（净资产收益率）= 净利润 / 净资产**
- 阈值：5 年平均 **≥15% 优秀**、≥10% 合格、<8% 淘汰
- 为什么：衡量股东每 1 元投入的回报。单年数据易受扰动（卖资产、补贴都能冲高一年），**5 年平均值**才代表真实盈利能力
- 关键补充——**杜邦拆解**：ROE = 净利率 × 总资产周转率 × 权益乘数。三种驱动来源的质量完全不同：
  - 高净利率驱动（定价权型，如高端白酒）→ 质量最高
  - 高周转驱动（效率型，如零售）→ 质量较高
  - **高杠杆驱动（如负债率 75% 以上）→ 质量最低**，系统对权益乘数 >3 的 ROE 直接打 8 折、>4 打 6 折
- 年报核查方向：ROE 结构突然变化时，查 MD&A 与主要科目附注

**毛利率 = （营收−成本）/ 营收**
- 阈值：**关键是稳定性而非绝对值**。35%+ 较好；5 年标准差 >3% 说明定价权不稳
- 为什么：长期稳定的高毛利通常意味着某种护城河（品牌 / 成本 / 转换成本）。毛利率突然跳升要警惕（会计手法），突然下滑要查原因（竞争加剧 / 成本失控）
- 年报核查方向：毛利率变动 >3pct 时，查「营业收入」与「营业成本」附注的分产品明细

**扣非净利率占比 = 扣非净利 / 净利**
- 阈值：**<60% 黄旗**，<50% 高度警惕
- 为什么：扣非净利润剔除了卖资产、政府补助、公允价值变动等一次性项目——这一块才反映主业真实盈利。利润靠一次性项目撑着的公司不配估值溢价
- 年报核查方向：查「非经常性损益明细表」，盘点每一项的来源与可持续性

### ② 资产安全

**资产负债率 = 总负债 / 总资产**
- 阈值：非金融行业 **>70% 黄旗**（银行地产另论）
- 为什么：高杠杆放大周期波动——景气时 ROE 被推高（也是 ROE 要按杜邦来源打折的原因），逆风时最先倒下
- 更重要的细分：**有息负债**（要还本付息的）vs 无息经营占款（预收款、应付账款，是良性负债）。系统单列有息负债/总资产
- 年报核查方向：查有息负债的到期结构（一年内到期的比例）与利息保障倍数

**存贷双高（重点规则）**
- 触发：货币资金/总资产 >20% **且** 有息负债/总资产 >20%
- 为什么：**正常经营的公司不会一边账上趴着大额存款、一边持续借高息债**（除非有极特殊原因）。这是财务造假的经典特征——康美药业案发前（2017 年报）：账面货币资金 341 亿，同时有约百亿有息负债，**后来证实 299 亿货币资金根本不存在**
- 年报核查方向（关键）：查「货币资金」附注的**受限情况**（质押/冻结/共管）；把**利息收入与存款规模对照**——100 亿存款只收到 1 亿利息，存款大概率是假的

**应收账款/营收 + 应收增速 vs 营收增速**
- 阈值：占比 >50% 黄旗；**应收增速 − 营收增速 >30pct 黄旗**
- 为什么：应收是"没收到钱的收入"。增速缺口持续扩大 = 靠赊销堆收入、对下游议价能力恶化。这是暴雷的前置信号（收入先"做"上去，坏账两年后爆出来）
- 年报核查方向：查「应收账款」附注的**账龄结构**（1 年以内占比是否下降）与**前五大欠款方集中度**；对照信用政策是否放宽

**商誉 / 净资产**
- 阈值：**>30% 黄旗**（评分时系数最重的扣分项之一）
- 为什么：并购溢价形成的"空气资产"，减值直接吞噬净资产且不影响现金流——2018 年商誉减值潮，几十家公司一夜巨亏。商誉高 = 前几年的并购可能有"水分"
- 年报核查方向：查「商誉」附注 + **减值测试的关键假设**（收入增长率、折现率是否激进）；被并购标的的业绩承诺完成情况

**存货 / 营收**
- 阈值：看行业定（白酒存货是宝贝，服装存货是垃圾），重点是**趋势突变**
- 年报核查方向：查「存货」附注的结构与库龄；对比同行的跌价准备计提比例（计提显著偏低 = 在藏风险）

### ③ 现金流（排雷第一优先级）

**利润含金量 = Σ经营现金流 / Σ净利润（5 年累计）**
- 阈值：**>0.8 健康；<0.8 黄旗；<0.5 红灯（剔除）**
- 为什么：这是整套指标体系里最重要的一条。**净利润是观点，现金流是事实。** 5 年累计口径过滤了单年的波动；长期低于 0.5，说明利润大量是"纸面数字"——康得新、康美案发前该比值均长期恶化
- 年报核查方向：查「现金流量表补充资料」（净利润→经营现金流的逐项调节），定位是应收/存货吃掉了现金，还是非付现收益在撑利润

**经营现金流连续为负年数**
- 阈值：**连续 ≥2 年红灯（剔除）**
- 为什么：真实赚钱的生意不会长年收不回现金。一家"盈利"公司连年在烧经营现金，商业模式或收入真实性必有问题

**自由现金流（经营现金流 − 资本开支）**
- 意义：扣掉维持与扩张所需的投入后，股东真正能拿到的钱。长期为负的"成长故事"要问：钱烧在哪里、何时能转正

### ④ 成长

**营收 CAGR / 净利 CAGR（近 3 年）**
- 阈值：营收 CAGR ≥15% 优秀、≥10% 良好；净利 CAGR 应不低于营收 CAGR 太多
- 为什么：重点看**增长质量**——利润增速持续显著高于营收增速，要么是提价能力（好事），要么是费用粉饰（查销售费用率与减值计提）
- 对照要求：成长必须由现金流背书（"有利润的增长" vs "有现金流的增长"）

**增速稳定性（营收增速标准差）**
- 为什么：忽上忽下的增长难以预测、常靠并购并表；平稳增长更能说明经营质地

### ⑤ 股东回报与估值

**股息率 = 每股分红 / 股价**
- 阈值：≥3% 较好（对照无风险利率）；但**连续性比单年高低更重要**
- 为什么：现金分红是最难造假的回报方式（要真金白银掏钱）。连续 5 年以上分红 = 股东回报意愿稳定

**分红率 = 分红 / 净利润**
- 合理区间：30%–70%。过高（>80%）要问可持续性 + 大股东资金需求；过低要问钱去哪了
- 危险组合：**一边大额分红、一边大额融资**（利益输送嫌疑）
- 年报核查方向：查「利润分配方案」与资本开支/融资计划的匹配性

**PE / PB**
- 使用纪律：**绝对水平没有意义**——要"三比"：与自身历史分位比、与同业比、与增速比（PEG）
- 系统当前版本提供水平值与简单分档；历史分位与同业对比是后续扩展方向（README 第 2 条）

## 四、评分规则（五维 = 100 分制）

| 维度 | 权重 | 打分构成 |
|---|---|---|
| 盈利质量 | 0.30 | ROE 水平 50%（含杠杆折扣） + ROE 稳定性 25% + 毛利率 25% |
| 资产安全 | 0.20 | 100 分起扣：存贷双高 −35｜负债率超标每 1pct −1.5｜商誉超标每 1pct −1.8｜应收超标按比例 |
| 现金流 | 0.20 | 含金量 70% + 自由现金流正负 30% |
| 成长 | 0.15 | 营收 CAGR 60% + 净利 CAGR 40% |
| 估值 | 0.15 | PE 分档 55% + 股息率分档 45% |

**评级**：A ≥80 · B ≥65 · C ≥50 · D <50

打分是阶梯式规则（每档阈值写死在 scoring.py 顶部），**任何一分都能回溯到具体数值** —— 你可以不认同某条规则，但你必须能看见它。改规则请连同 config 权重一起考虑。

## 五、年报核查清单的设计逻辑

系统的核心信念：**财报数据是体温计，真正的病因在年报原文里。**

所以每个财务异常都会自动生成一条核查任务，格式为：

```
【核查主题】（依据：触发的财务数据）
   📍 去哪查：年报的具体章节/附注
   🔍 查什么：具体的核查动作（看什么、对照什么、识别什么）
```

两类核查：
- **通用核查（4 条，每家公司都做）**：审计意见 → 关键审计事项（KAM）→ MD&A → 股东质押与增减持
- **定向核查（数据触发）**：应收异常→账龄结构；存贷双高→受限资金+利息收入匹配；商誉→减值测试假设；含金量不足→现金流调节表……（共 10 条规则）

这样"读年报"从"通读 200 页"变成"带着 5-15 个具体问题定向核查"。

## 六、使用这套指标的正确姿势

1. **阈值是起点不是终点**：config 里的每条阈值都可根据你的风险偏好调整——但调整前先想清楚"为什么"；
2. **先排雷后选美**：先读个股报告的第九节（排雷清单）与第十节（核查清单），再看亮点；
3. **数据会骗人，原文不会**（原文也可能骗，但至少没有中间商）：黄旗全部去年报核查后再下结论；
4. **建立自己的能力圈档案**：每分析一家，把结论与核查结果写进 Obsidian，一年后你会拥有别人没有的东西——50 家公司的第一手研究档案。
